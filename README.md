# Samad (Council Review Management System)

A university project developed for the **Project** course at **IAU** (Islamic Azad University). The core concept, workflow, and system requirements were proposed and supervised by **Dr. Shafiabadi**.

---

## Project Overview
**Samad** is a comprehensive automated workflow system designed to streamline the document review process. It facilitates seamless document uploading by applicants, collaborative evaluation by council members, and final decision-making by the council secretary.

## Tech Stack
* **Framework:** .NET 
* **ORM:** Entity Framework Core
* **Architecture:** Clean Architecture

## Key Features
* Role-based access control (Applicant, Council Member, Secretary, Admin).
* Automated state management for document approvals and revisions.
* Secure and structured data modeling using Fluent API configurations.
